# 経費仕訳 分類アシスタント

以下の支出を、法人の経費として適切に分類してください。

支出情報：$ARGUMENTS

## 出力形式（Googleスプレッドシート用）

日付 / 金額（税込） / 金額（税抜） / 消費税額 / 勘定科目 / 摘要 / インボイス要否 / メモ

## よく使う勘定科目
- Apple Storeでの仕入れ → 仕入高
- カード購入（転売目的） → 仕入高
- メルカリ・ラクマ手数料 → 支払手数料
- 梱包材・OPP袋・段ボール → 消耗品費
- 送料 → 荷造運賃
- 交通費（Apple Store往復） → 旅費交通費
- 携帯電話・通信費 → 通信費

## 消費税の取り扱い
- インボイスあり → 仕入税額控除100%
- 個人からの仕入れ（古物商特例）→ 2026年9月まで80%控除可能

⚠️ 最終確認は税理士に。事業年度は7月1日〜6月30日。
