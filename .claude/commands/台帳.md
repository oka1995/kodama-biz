# 古物台帳 記録エントリ作成

以下の取引情報をもとに、古物営業法に基づく古物台帳の記録エントリを作成してください。

取引情報：$ARGUMENTS

## 出力形式（Googleスプレッドシート貼り付け用・タブ区切り）

取引日 / 取引区分 / 品目 / 数量 / 取引金額 / 相手方氏名 / 相手方住所 / 本人確認方法 / 特記事項

## 注意事項（古物営業法の要件）
- 個人から仕入れた場合：氏名・住所・本人確認書類の種類を必ず記録
- 法人から仕入れた場合：法人名・代表者名・所在地を記録
- 1万円以上の取引：本人確認が法的義務
- 取引記録は3年間保存が義務

取引相手の情報が不足している場合は、不足項目を明示して入力を促してください。

⚠️ 不明な点は警察署（防犯係）または専門家にご確認ください。
