# 仕入れ採算計算

以下の情報をもとに、この仕入れ案件の採算を計算してください。

案件情報：$ARGUMENTS

## iPhone案件の場合
1. 仕入れ原価（Apple Store購入価格＋交通費等）
2. 売却予想額（業者買取相場）
3. 粗利額・粗利率
4. 消費税の影響（仕入税額控除あり）
5. 1台あたりの手取り利益（税引前）

## トレーディングカード案件の場合
1. 仕入れ原価
2. 売却予想額（フリマ相場 or 業者相場）
3. 手数料控除後の手取り
   - メルカリ手数料：10%
   - ラクマ手数料：4.5%
4. 粗利額・粗利率
5. 古物台帳記録の要否（1万円以上なら要本人確認）

結果はスプレッドシートに貼り付けやすい表形式でも出力してください。

⚠️ 税務上の判断は税理士にご確認ください。
